# Dragging Papers 🧾

Inspired by [Develpoer Rahul](https://github.com/developerrahulofficial) work and built with his guidance.

link mobile.js instead of script.js in index.html to work in mobile.

A simple drag-and-drop web application where users can place, move, and arrange pieces of paper on a canvas. The project focuses on basic interaction, smooth dragging experience, and a minimal UI.

## 🚀 Features
- Drag and drop paper elements
- Smooth movement on canvas
- Simple and clean interface
- Lightweight and easy to use

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
